================================================================================
                          KEY COMPONENTS EXPLAINED
================================================================================

1. LANDING PAGE (client/src/pages/home.tsx)
   Purpose: Showcase product features and convert visitors
   Sections: 
     - Sticky header with navigation
     - Hero section (headline + phone mockup)
     - Problem explanation (3 fitness pitfalls)
     - 2x2 feature grid (AI features)
     - Testimonials carousel
     - Final CTA section
     - Footer with links
   Key: All elements have test IDs for automation

2. CHATBOT (client/src/components/ChatBot.tsx)
   Purpose: AI-powered customer support widget
   Features:
     - Floating button (bottom-right)
     - Expandable chat interface
     - Real-time streaming responses
     - Message history (localStorage persisted)
     - Rate-limited (20 req/hour)

3. API ENDPOINT (/api/chat)
   Purpose: Stream OpenAI responses
   Input: { message: string, previousResponseId?: string }
   Output: Server-Sent Events (text/event-stream)
   Authentication: Rate-limited by client IP
   AI Prompt: Customer support for MuscleCoach (fitness knowledge)

================================================================================
                        DEVELOPMENT WORKFLOW
================================================================================

GETTING STARTED:
  1. npm install
  2. Set OPENAI_API_KEY environment variable
  3. npm run dev (start development server)
  4. Open browser to Replit dev URL
  5. Changes auto-reload (HMR)

COMMON COMMANDS:
  npm run dev        - Start development server
  npm run build      - Build for production
  npm start          - Run production build
  npm run check      - Type check without building
  npm run db:push    - Apply database migrations (if using DB)
