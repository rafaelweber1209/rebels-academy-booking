█ VALIDATION RULES
═════════════════════════════════════════════════════════════════════════════

FIELD: Name
  Type: String
  Required: Yes
  Client Validation: Min 1 character
  Server Validation: Min 1 character
  Error: "Name is required"

  Type: Email
  Required: Yes
  Client Validation: Valid email format
  Server Validation: Valid email format
  Error: "Invalid email address"

  Type: Date (ISO format)
  Required: Yes
  Client Validation: Date selected
  Server Validation: Not empty string
  Error: "Preferred date is required"

FIELD: Message
  Type: String
  Required: No
  Client Validation: None (optional)
  Server Validation: None (optional)
  Default: "" (empty string)

█ COMMON ISSUES & SOLUTIONS
═════════════════════════════════════════════════════════════════════════════

ISSUE: Form doesn't appear on page
FIX:   Check that BookingForm component is imported in home.tsx

ISSUE: "Notion is niet geconfigureerd" error
FIX:   1. Check NOTION_API_KEY and NOTION_DATABASE_ID are set
       2. Restart dev server after setting env variables
       3. In Replit, use Secrets panel to set values

ISSUE: Form submits but nothing in Notion
FIX:   1. Check API key is correct (copy from notion.com/my-integrations)
       2. Verify database ID matches Notion URL
       3. Ensure database is shared with integration
       4. Check column names match exactly (case-sensitive)

ISSUE: Column type mismatch error from Notion API
FIX:   Ensure column types in Notion are:
       • Name: Title type (required for Notion databases)
       • Email: Email type
       • Preferred Date: Date type
       • Message: Text or Rich Text type
       • Status: Status type

ISSUE: 401 Unauthorized from Notion API
FIX:   1. Verify API key hasn't expired (generate new one)
       2. Copy token again from my-integrations page
       3. Make sure integration still exists

ISSUE: Browser shows network error
FIX:   1. Check dev server is running (npm run dev)
       2. Check server console for errors
       3. Verify API endpoint exists: POST /api/bookings

ISSUE: Form validation passes but server rejects data
FIX:   This shouldn't happen - report as bug with full error message
